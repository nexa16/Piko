# Piko

Piko is a local-first Flutter vocabulary app with English and German interface languages. Organize words in Collections, add examples and hints, and practice with Long-term or Speed learning. Vocabulary and learning state stay on the device.

- [Feature guide](docs/features.md) — pages, tasks, terminology and current limitations
- [Product screenshots](docs/screenshots.md) — authentic ordinary-app captures with synthetic content
- [Technical reference](docs/technical.md) — architecture, storage, learning and JSON compatibility
- [Developer setup](docs/development.md) and [documentation maintenance](docs/maintenance.md)
- [Documented build and capture manifest](docs/build-manifest.json) and [verification coverage](docs/verification.md)

This is a development application, not a declared store release. See [contribution workflow](CONTRIBUTING.md) and [security guidance](SECURITY.md).

No open-source license has been selected. Public visibility alone does not grant reuse rights.
