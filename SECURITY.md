# Security

## Private reporting

Use GitHub private vulnerability reporting when enabled: open the repository's Security tab, choose Advisories, and select Report a vulnerability. The reporting entry point is https://github.com/nexa16/Piko/security/advisories/new.

If private reporting is unavailable, do not disclose the vulnerability in a public Issue. Request that the owner enable private reporting without including sensitive details, and wait for a private reporting channel.

Do not open public Issues or Pull Requests containing secrets, personal data, or sensitive exploit details. No private email address is published here.

## Exposed credentials

An accidentally committed credential must be revoked or rotated immediately. Deleting it from the latest commit does not remove it from history or invalidate copies. After revocation, coordinate history cleanup and review the credential's use and access.
