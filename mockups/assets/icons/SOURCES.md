# Icon comparison sources

Official unmodified SVGs with upstream license notices retained. Lucide is selected for Piko's interface (2026-10-13). Phosphor and Tabler remain historical comparison assets, not active UI dependencies.

The collection menu also uses `ellipsis.svg` from the same pinned Lucide revision below.

Lucide UI roles use pencil, trash, check, x, arrow-left, rotate-ccw, chevron-right, zap, chart-no-axes-column, list-filter, layers, upload, grid-2x2, plus and settings from the same pinned revision below. CSS masks use these local originals and inherit semantic color; no runtime CDN is required. Keep LICENSE.txt when reusing or redistributing the assets.
